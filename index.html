How it works

Local proxy. Real-time control.

Fleasion routes Roblox Player asset traffic through a local HTTPS proxy. When Roblox requests an asset, Fleasion can let it through, replace it, remove it, redirect it, or capture it for inspection.

Technical details on GitHub →
  1. 01

    Launch Fleasion

    The desktop app starts its local proxy and lives in the system tray. Open the Dashboard whenever you want to configure or inspect it.

  2. 02

    Build your setup

    Create replacement profiles, enable client modifications, configure advanced FastFlags, or turn on the live scraper.

  3. 03

    Launch Roblox

    Env Proxy mode relaunches Roblox Player with a scoped proxy environment. A Hosts File compatibility mode is also available.

  4. 04

    Replace or capture on demand

    As assets are requested, Fleasion applies your rules and can collect originals into its cache viewer for preview, conversion, and export.

FAQ

Frequently asked questions.

For troubleshooting and feature-specific caveats, the GitHub README and Discord community have the most detail.

How do I install Fleasion?

Download the standalone build for your platform from GitHub Releases. Python 3.14+ and uv are only needed if you choose to run or build Fleasion from source.

What can Fleasion replace?

Replacement rules can target Roblox assets by ID or asset type and point to another asset ID, a URL, a local file, or an empty replacement to remove supported content. The scraper recognizes dozens of Roblox asset types.

Does Fleasion modify Roblox servers?

No. Fleasion's normal replacement and capture workflows happen locally on your machine by intercepting Roblox Player traffic through a local proxy. Other players do not see your ordinary client-side asset replacements.

Is every Fleasion feature risk-free?

No. Roblox has stated that client modifications are not permitted, and game moderation can still take action. Custom FastFlags are especially advanced: they bypass Roblox's small locally permitted allowlist and may carry account risk. Fleasion displays a confirmation before enabling them. Use advanced modifications with your own judgment.

Where should I download Fleasion?

Use only the official GitHub Releases page. The project repository and Fleasion community links below are the canonical sources.
